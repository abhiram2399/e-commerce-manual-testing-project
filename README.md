# E-Commerce Website Manual Testing Project

## 📌 Project Overview

This project demonstrates manual functional testing of an
e-commerce website.

The objective was to verify major e-commerce functionalities,
design and execute test cases, perform manual test execution,
and document the testing results.

---

## 🌐 Application Tested

**Application:** SauceDemo

**Application Type:** E-Commerce Web Application

**Testing Type:** Manual Testing
